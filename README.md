# Aavin Security Booking Count

A booking tracking system for Aavin Security with OCR-based data capture.

## Branches

| Branch | Description |
|--------|-------------|
| `main` | Stable production branch |
| `ocr`  | OCR-based booking tracking feature development |

## Project Overview

This system tracks security bookings for Aavin using Optical Character Recognition (OCR) to automate data entry and booking count management.
